# rssla.org
UCLA RSS Website




Clone the repository by running this in your terminal:

```
git clone https://github.com/rishisankar/rssla.org.git
```

Now, enter the repository:

```
cd rssla.org
```

Run the following command to install dependencies:

```
npm install
```

Run the following command to run the site:

```
npm start
```

How to upload changes to the actual website
Run: 
npm run build

replace the static folder and index.html in the cPanel file manager
